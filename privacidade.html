Política de Privacidade — Claudinho

Última atualização: 29 de outubro de 2026

O que é

O Claudinho é uma ferramenta pessoal usada exclusivamente pelo criador de conteúdo Toninho Goiás para analisar o desempenho das próprias contas. Não é oferecido a terceiros.

Quais dados são acessados

Com autorização expressa do titular, via OAuth oficial, o Claudinho lê em modo somente leitura:

  • YouTube Data API e YouTube Analytics API: dados públicos do canal e dos vídeos (títulos, descrições, contagens de visualizações, curtidas e comentários) e relatórios agregados de desempenho (tempo assistido, retenção, inscritos ganhos).
  • Instagram (API oficial da Meta): perfil, publicações e estatísticas agregadas da conta profissional do titular.
  • TikTok (Login Kit e Display API): perfil, contagem de seguidores e curtidas, e lista de vídeos públicos do titular com suas contagens de visualizações, curtidas, comentários e compartilhamentos.

Não são acessados dados pessoais de espectadores além do que as plataformas já entregam de forma agregada.

Como os dados são usados e armazenados

  • Os dados ficam armazenados apenas no computador do titular, em banco de dados local.
  • Os tokens de acesso ficam no Gerenciador de Credenciais do sistema operacional do titular.
  • Os dados não são vendidos, compartilhados nem transferidos a terceiros, e não são usados para publicidade.
  • O Claudinho não publica, não apaga, não comenta e não altera nada nas contas.

Uso de dados das APIs do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O Claudinho usa os serviços de API do YouTube e concorda com os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O titular pode revogar o acesso a qualquer momento em myaccount.google.com/permissions e apagar os dados locais excluindo o banco de dados do próprio computador.

Contato
